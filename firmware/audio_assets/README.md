# DFPlayer audio — warm-up announcement

## Standar suara produk (WAJIB)

| Item | Nilai |
|------|-------|
| Voice | **`en-US-JennyNeural`** (wanita, ramah) |
| Engine | `edge-tts` (Microsoft Edge TTS) |
| Aturan | Semua clip baru **harus** pakai voice yang sama — lihat `D01E_HMI_DEVNOTE.md` §7.4 |

---

| File | Voice | Text |
|------|-------|------|
| `0001.mp3` | en-US-JennyNeural (female) | "The warm-up is almost complete" |

Source: `audio_assets/0001.mp3` (generated by `scripts/gen_warmup_audio.py`).

## microSD setup (DFPlayer U13)

1. Format microSD **FAT32**.
2. Copy **`0001.mp3`** ke **root** kartu SD (nama persis `0001.mp3`).
3. Masukkan ke modul DFPlayer Mini.
4. Volume default firmware: **25** (0–30). Sesuaikan `DF_VOLUME` di `config.h` jika perlu.

## Regenerate audio

```bash
python scripts/gen_warmup_audio.py
```

## Playback (firmware)

- Saat **page4** warming up dan **BT ≥ 175°C** (belum 180°C): putar track **1** berulang setiap **3 detik**.
- Berhenti otomatis saat BT ≥ 180°C atau user keluar page4.

## Uji tanpa mesin

1. Flash ESP32 + pasang SD dengan `0001.mp3`.
2. Buka page4 dengan BT < 175°C (atau simulasi suhu di serial).
3. Naikkan suhu melewati 175°C → speaker memutar pengumuman.
